# 잠소리

자는 동안 휴대폰으로 소리를 듣고 **코골이를 몇 분 했는지**, **어떤 패턴인지**, **호흡이 멈추는 것처럼 보이는 구간이 얼마나 되는지** 분석하는 웹앱입니다. 설치할 것 없이 브라우저에서 돌아가고, 기록은 그 기기 안에만 저장됩니다.

> 이 앱은 진단 도구가 아니라 선별(스크리닝) 도구예요. 수면무호흡은 병원의 수면다원검사로만 확진할 수 있습니다.

## 바로 실행하기 (PC)

```bash
npm start
```

브라우저에서 http://localhost:5173 을 엽니다. 마이크는 `https://` 주소나 `localhost`에서만 켜지기 때문에 파일을 더블클릭해서 열면 안 되고, 위 서버로 열어야 합니다.

처음에는 **리포트 → 예시 기록 불러오기**로 7일치 예시 데이터를 넣어 보면 화면 구성을 한눈에 볼 수 있어요.

## 아이폰에 앱으로 설치하기

잠소리는 홈 화면에 추가하는 웹앱(PWA)이에요. 앱스토어 없이 무료로 설치되고, 한 번 열어 두면 인터넷 없이도 열립니다.

**1단계: https 주소에 올리기** — 아이폰은 `https` 주소에서만 마이크를 허용해요. 이 폴더는 빌드가 필요 없는 정적 파일이라 그대로 올리면 됩니다.

GitHub Pages (무료, 계속 유지됨)
1. https://github.com/new 에서 저장소 만들기 (예: `jamsori`, Public)
2. 저장소 화면의 **uploading an existing file**을 눌러 이 폴더 안의 파일과 폴더를 전부 끌어다 놓고 **Commit changes**
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1–2분 뒤 `https://내아이디.github.io/jamsori/` 주소가 생겨요

또는 Netlify Drop: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓기 (계정을 만들어야 주소가 유지돼요)

올려도 녹음 데이터는 서버로 가지 않아요. 서버는 화면 파일만 내려주고, 분석과 저장은 전부 휴대폰 안에서 일어납니다.

**2단계: 홈 화면에 추가**
1. 아이폰 **Safari**로 위 주소 열기
2. **공유** 버튼 → **홈 화면에 추가** → **추가**
3. 홈 화면의 잠소리 아이콘으로 열고, 처음 녹음할 때 마이크 권한 **허용**

앱 첫 화면에도 같은 안내가 나와요. Safari와 홈 화면 앱은 기록을 따로 저장하니, 설치한 뒤에는 앱에서만 녹음하세요. 홈 화면 앱으로 쓰면 오래 안 열어도 기록이 지워지지 않아요.

**아이폰에서 밤새 녹음하려면** 웹앱은 화면이 잠기면 마이크가 멈춰요.
- 설정 → 디스플레이 및 밝기 → 자동 잠금 → **안 함**
- **저전력 모드 끄기** (켜져 있으면 자동 잠금이 30초로 고정돼요)
- 녹음 중에는 다른 앱으로 넘어가지 말고 "화면 어둡게"로 검은 화면 유지
- 충전기 연결

화면을 끈 채로 녹음하려면 진짜 iOS 앱(네이티브)이 필요해요. 그러려면 Mac과 Xcode, 그리고 아이폰에 오래 설치해 두려면 Apple Developer Program(연 99달러)이 필요합니다. 아래 "다음에 해볼 만한 것"을 참고하세요.

## 안드로이드에서 쓰기

위와 같은 https 주소를 크롬으로 열고 메뉴 → **홈 화면에 추가**(또는 **앱 설치**)를 누르면 됩니다.

같은 와이파이에서 잠깐 테스트만 해볼 때는 이렇게 할 수 있어요(안드로이드 크롬만):
1. PC에서 `npm start`, PC의 IP 주소 확인 (`ipconfig`)
2. 휴대폰 크롬 주소창에 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` → `http://PC의IP:5173` 추가 → 다시 시작
3. 휴대폰에서 `http://PC의IP:5173` 열기

### 밤에 쓰는 법
- 충전기를 꽂고, 휴대폰을 머리맡 50cm–1m 거리에 둡니다.
- 앱이 화면 꺼짐을 막아 두지만, 지원하지 않는 브라우저(특히 아이폰)는 **설정 → 디스플레이 → 자동 잠금 → 안 함**으로 바꿔 주세요. 화면이 꺼지면 브라우저가 마이크를 멈출 수 있어요.
- 녹음 중 "화면 어둡게"를 누르면 화면이 완전히 검게 됩니다. 녹음은 계속돼요.
- 화면이 꺼져서 녹음이 멈췄던 시간은 자동으로 알아내서 분석 시간에서 빼고, 그 사이를 호흡 멈춤으로 세지 않아요.
- 끝낼 때는 **녹음 끝내기를 두 번** 누릅니다. 자다가 실수로 끄는 걸 막기 위해서예요.

## 무엇을 알려주나요

| 지표 | 뜻 |
|---|---|
| 코골이 시간 (분) | 1분 안에 코골이가 3번 이상 들린 분의 수 |
| 코골이 비율 | 코골이 시간 ÷ 분석한 시간 (잠들기 전 제외 시간, 녹음 끊김 제외) |
| 강도 약/중/강 | 주변 소음(바닥 소음)보다 12dB 미만 / 12–20dB / 20dB 이상 |
| 호흡 멈춤 의심 (회/시간) | 규칙적으로 코를 골다가 10초 넘게 소리가 끊기고, 다시 크게 헉 하며 코골이가 이어지는 횟수. 병원의 AHI(무호흡-저호흡 지수) 기준(5/15/30)에 맞춰 등급을 보여 주지만 같은 값은 아니에요 |
| 시간대 치우침 | 전반부에 몰리면 술·피로·진정제, 후반부에 몰리면 렘수면 관련 가능성 |
| 켜졌다 꺼짐 | 5–45분짜리 구간이 반복되면 자세(똑바로 누운 자세) 영향 가능성 |
| 리듬 규칙성 | 숨 간격과 소리 크기가 들쭉날쭉하면 단순 코골이보다 수면무호흡에서 흔한 모양 |
| 소리 높이 | 300Hz 미만은 연구개(입천장 뒤) 쪽, 800Hz 초과는 혀뿌리·후두개 쪽 소리와 비슷 (참고용) |
| 요인 비교 | 음주·옆으로 자기·코막힘 등을 체크한 밤과 안 한 밤의 평균 코골이 비율 차이 |

**건강 체크** 탭의 STOP-Bang 설문(8문항)을 녹음 결과와 함께 보여 줘서, 둘 다 위험을 가리키면 검사를 권합니다.

호흡 멈춤 의심 구간과 큰 코골이는 **짧은 확인용 클립**(WAV, 최대 18개)으로 저장돼서 직접 들어보거나 진료 때 들려줄 수 있어요. 밤 전체 원본은 저장하지 않습니다.

## 코골이를 찾는 방법

```
마이크 → 16kHz로 줄이기 → 64ms 프레임마다 크기(dB)·스펙트럼 계산
      → 바닥 소음 추적 (천천히 올라가고 빨리 내려감 → 선풍기·에어컨 같은 일정한 소음은 자동으로 걸러짐)
      → 바닥 소음보다 5dB 이상 커진 구간 = 소리 이벤트
      → [1차] 코골이 후보: 0.25–4초, 800Hz 이하 에너지 45% 이상, 무게중심 1100Hz 이하, 너무 평평하지 않은 스펙트럼
      → [2차] 숨 리듬 확인: 앞뒤 45초 안에 후보가 4개 이상이고 간격 중간값이 1.8–10초(분당 6–33회 호흡)
      → 코골이 확정 → 분 단위 집계, 구간, 호흡 멈춤, 패턴 문장
```

2차 리듬 확인이 핵심입니다. 말소리, TV, 문소리, 뒤척임은 소리 자체가 비슷하더라도 "숨 쉬는 간격으로 반복"되지 않기 때문에 걸러집니다.

판단 기준값은 모두 [js/analysis.js](js/analysis.js) 위쪽 `SENSITIVITY`, `RULES`에 모여 있어서 조절하기 쉬워요. 기록에는 소리 특징이 저장돼 있으니 리포트에서 민감도를 바꾸면 바로 다시 분석됩니다.

## 테스트

```bash
npm test
```

[test/synth.js](test/synth.js)가 코골이, 호흡 멈춤 4번, 말소리, 문소리, 선풍기 소음을 섞은 20분짜리 가짜 밤 소리를 만들고, 검출 결과를 정답과 비교합니다. 지금 결과는 코골이 220/220회 검출, 오검출 0회, 호흡 멈춤 4/4회, 녹음 끊김을 호흡 멈춤으로 세지 않음입니다.

합성음은 실제 코골이보다 깨끗해서, 실제 녹음으로 며칠 써 보면서 `RULES` 값을 다듬는 게 다음 단계예요.

## 알 수 없는 것

- 혈중 산소 감소, 뇌파로 본 수면 단계 (병원 검사나 스마트워치가 필요)
- 코골이 없이 생기는 무호흡 (중추성 수면무호흡)
- 옆 사람 코골이와 내 코골이의 구별
- 정확한 소리 크기(dB SPL). 휴대폰마다 마이크 감도가 달라서 "주변 소음 대비 몇 dB"로만 봅니다.

## 파일 구조

```
index.html          화면 구조
styles.css          스타일 (다크 기본, 라이트 지원)
js/detector.js      소리 이벤트 검출 (FFT, 바닥 소음, 이벤트 자르기)
js/analysis.js      코골이 판정, 밤 분석, 결과 문장, 여러 밤 비교  ← 핵심 로직
js/recorder.js      마이크/파일 입력, 링버퍼, 확인용 클립, 화면 꺼짐 방지
js/worklet.js       오디오 스레드에서 샘플 모으기
js/storage.js       IndexedDB 저장
js/charts.js        SVG 차트
js/demo.js          예시 기록 생성
js/app.js           화면 흐름
sw.js               서비스 워커 (인터넷 없이도 앱이 열리게 파일 저장)
manifest.webmanifest, icons/   홈 화면 앱 이름과 아이콘
scripts/make-icons.js          아이콘 PNG 다시 만들기
test/               합성음과 자동 테스트
server.js           개발용 서버 (의존성 없음)
```

`detector.js`와 `analysis.js`는 브라우저 기능을 쓰지 않는 순수 자바스크립트라서, 나중에 React Native·Capacitor 앱이나 서버로 그대로 옮길 수 있어요.

## 다음에 해볼 만한 것

- **네이티브 앱으로 감싸기** (Capacitor 등): 화면을 꺼도 밤새 녹음되게 하려면 앱의 백그라운드 녹음 권한이 필요합니다.
- **머신러닝 분류기 추가**: 코골이·말소리·기침을 구분하는 오디오 분류 모델(예: YAMNet)을 1차 후보 판정에 더하면 실제 환경에서 더 정확해집니다.
- **스마트워치 산소포화도 연동**: 소리로 본 호흡 멈춤과 산소 감소가 겹치는지 보면 훨씬 믿을 만해집니다.
